# 运行说明

本目录是「校遇」的前端工程源码，来自实际生产项目的构建源。

## 本地运行

```bash
npm install
npm run dev     # 默认 http://localhost:5173
```

`vite.config.js` 中已将 `/api` 与 `/socket.io` 代理到 `http://localhost:3000`，需要配套后端服务才能完整运行。

由于本展示仓库不包含服务端实现，直接启动前端时页面可以渲染，但所有数据请求会失败 —— 这是预期行为。若需要完整效果，请访问线上站点。
